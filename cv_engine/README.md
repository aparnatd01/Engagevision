# cv_engine — DAiSEE + MobileNetV2 Engagement Classification Engine

> CPU-optimized engagement predictor for the EngageVision system.
> Trained on the [DAiSEE](https://people.iith.ac.in/vineethnb/resources/daisee/index.html) dataset.

---

## Directory Structure

```
cv_engine/
├── __init__.py          # Package init — exports EngagementPredictor
├── config.py            # All constants: model architecture, thresholds, paths
├── model.py             # MobileNetV2 architecture builder + load/save
├── dataset.py           # DAiSEE label parsing, frame extraction, face cropping
├── predictor.py         # Inference API — the main integration point
├── train.py             # Standalone training script (CLI)
├── verify_setup.py      # System & dependency verification
├── models/
│   └── engagement_model.h5   # Trained model weights (generated by train.py)
└── README.md            # This file
```

## Quick Start

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Verify Setup

```bash
python -m cv_engine.verify_setup
```

### 3. Download DAiSEE Dataset

**Option A — Official (IIT Hyderabad):**
Visit [https://people.iith.ac.in/vineethnb/resources/daisee/index.html](https://people.iith.ac.in/vineethnb/resources/daisee/index.html)
and fill out the request form.

**Option B — Kaggle:**
Download from [https://www.kaggle.com/datasets/smeeshanthini/daisee](https://www.kaggle.com/datasets/smeeshanthini/daisee)

Place the dataset so it has this structure:
```
DAiSEE/
├── DataSet/
│   ├── Train/
│   ├── Test/
│   └── Validation/
└── Labels/
    ├── TrainLabels.csv
    ├── TestLabels.csv
    └── ValidationLabels.csv
```

### 4. Train the Model

```bash
python -m cv_engine.train --dataset_dir DAiSEE/DataSet --labels_dir DAiSEE/Labels
```

Training takes approximately:
- **2-4 hours** on a GPU (Google Colab free tier)
- **6-12 hours** on CPU (Intel i7-1355U)

The trained model is saved to `cv_engine/models/engagement_model.h5` (~14 MB).

### 5. Test Inference

```python
from cv_engine.predictor import EngagementPredictor
import cv2

predictor = EngagementPredictor()
face = cv2.imread('test_face.jpg')
result = predictor.predict(face)

print(result)
# {'engagement_pct': 71.5, 'level': 'High', 'probabilities': [...], ...}
```

## How It Works

### Pipeline

```
Face Crop (BGR, any size)
    │
    ▼
Resize to 224×224, BGR→RGB, normalize [0,1]
    │
    ▼
MobileNetV2 (frozen ImageNet backbone)
    │
    ▼
GlobalAveragePooling2D → Dense(128) → Dense(4, softmax)
    │
    ▼
Softmax output: [p_very_low, p_low, p_high, p_very_high]
    │
    ▼
Weighted score: Σ(prob_i × weight_i) × 100  →  engagement_pct (0-100%)
    │
    ▼
Level: ≥66% → High, ≥33% → Medium, <33% → Low
```

### DAiSEE Label Mapping

| DAiSEE Label | Numeric | EngageVision Level |
|---|---|---|
| Very High | 3 | **High** (Green) |
| High | 2 | **Medium** (Yellow) |
| Low | 1 | **Low** (Red) |
| Very Low | 0 | **Low** (Red) |

### Engagement Percentage Formula

```
engagement_pct = (p_very_low × 0.0 + p_low × 0.33 + p_high × 0.66 + p_very_high × 1.0) × 100
```

## Integration with EngageVision

The monitoring analyzer (`app/monitoring/analyzer.py`) will use:

```python
from cv_engine.predictor import EngagementPredictor

# Initialize once (at app startup)
predictor = EngagementPredictor()

# For each detected face crop:
result = predictor.predict(face_crop_bgr)
engagement_score = result['engagement_pct']   # e.g., 71.5
engagement_level = result['level']            # e.g., 'High'
```

## Configuration

All constants are in `cv_engine/config.py`. Key settings can be overridden
via environment variables:

| Variable | Default | Description |
|---|---|---|
| `ENGAGEMENT_MODEL_PATH` | `cv_engine/models/engagement_model.h5` | Model file location |
| `DAISEE_DATASET_DIR` | `DAiSEE/DataSet` | Dataset directory |
| `DAISEE_LABELS_DIR` | `DAiSEE/Labels` | Labels directory |
